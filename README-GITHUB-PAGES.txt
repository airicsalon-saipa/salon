# GitHub Pages static upload

Upload the **contents of this folder** to the root of a GitHub repository, then enable GitHub Pages for the repository.

This static build includes team selection, player profiles, hall schedules, the photo/video gallery, and read-only news. Member login, attendance polls, and the in-app player-rating form have been removed. The player evaluation page is ready for a Google Forms link; it will be activated when that link is provided.

Team selections and player tag changes are saved only in the visitor's browser. They are not shared between visitors.

Do not add private credentials or account files to a public repository.

The live news panel is read-only and shows all announcements in a vertical scrolling rail on wide screens.
